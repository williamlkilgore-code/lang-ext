# Browser Compatibility Guide

## Quick Start

### For Firefox Users
```bash
npm run firefox
# Then load the extension in Firefox: about:debugging#/runtime/this-firefox
```

### For Chrome/Edge Users
```bash
npm run chrome
# Then load the extension in Chrome: chrome://extensions (Enable Developer Mode)
```

## Files Overview

| File | Purpose | Commit to Git? |
|------|---------|----------------|
| `manifest.json` | **Active manifest** (auto-generated, switches based on browser) | ❌ No |
| `manifest-v2.json` | **Firefox template** (Manifest V2) | ✅ Yes |
| `manifest-v3.json` | **Chrome template** (Manifest V3) - created by `npm run firefox` | ❌ No |
| `background/background.js` | Chrome background script (uses `chrome.action`) | ✅ Yes |
| `background/background-v2.js` | Firefox background script (uses `chrome.browserAction`) | ✅ Yes |

## How It Works

1. **Default state**: Repository includes `manifest-v2.json` (Firefox template) as the committed version
2. **Chrome setup**: Run `npm run chrome` to copy `manifest-v2.json` → `manifest-v3.json` and activate V3
3. **Firefox setup**: Run `npm run firefox` to activate V2 from `manifest-v2.json`
4. **Active manifest**: `manifest.json` is always the active one, auto-generated by npm scripts

## Key Differences

### Manifest V2 (Firefox)
```json
{
  "manifest_version": 2,
  "background": {
    "scripts": ["background/background-v2.js"],
    "persistent": false
  },
  "browser_action": { ... },
  "permissions": ["storage", "activeTab", "tabs", "<all_urls>"]
}
```

### Manifest V3 (Chrome)
```json
{
  "manifest_version": 3,
  "background": {
    "service_worker": "background/background.js"
  },
  "action": { ... },
  "permissions": ["storage", "activeTab", "tabs"],
  "host_permissions": ["<all_urls>"]
}
```

## Background Script Differences

### background-v2.js (Firefox)
- Uses `chrome.browserAction.setBadgeText()`
- Uses `chrome.browserAction.setBadgeBackgroundColor()`
- Runs as a persistent background script

### background.js (Chrome)
- Uses `chrome.action.setBadgeText()`
- Uses `chrome.action.setBadgeBackgroundColor()`
- Runs as a service worker (non-persistent)

## Development Workflow

### Making Changes

1. **Update shared code** (content scripts, utils, popup, options):
   - These files work in both browsers
   - No changes needed

2. **Update manifest** (if adding permissions, commands, etc.):
   ```bash
   # Edit both templates
   vim manifest-v2.json  # Firefox

   # Generate V3 by switching to Chrome mode
   npm run chrome
   vim manifest.json     # This is now V3

   # Copy changes back to committed template
   cp manifest.json manifest-v3-template.json
   ```

3. **Update background script** (if changing badge, commands, etc.):
   - Edit `background/background.js` for Chrome
   - Edit `background/background-v2.js` for Firefox
   - Keep changes synchronized between both files

### Testing in Multiple Browsers

```bash
# Terminal 1 - Firefox
npm run firefox
# Load in Firefox: about:debugging

# Terminal 2 - Chrome
npm run chrome
# Load in Chrome: chrome://extensions

# Make changes, reload extension in both browsers
```

## Git Workflow

### What to Commit
```bash
# Always commit these
git add manifest-v2.json              # Firefox template
git add background/background-v2.js   # Firefox background
git add background/background.js      # Chrome background

# NEVER commit these (auto-generated)
# manifest.json - active manifest (auto-generated)
# manifest-v3.json - Chrome backup (auto-generated)
```

### Example Workflow
```bash
# Make changes to extension
vim utils/settings.js

# Update both background scripts if needed
vim background/background.js
vim background/background-v2.js

# Update Firefox template
vim manifest-v2.json

# Generate Chrome version to test
npm run chrome

# Verify Chrome version works
# Then switch back to Firefox as default
npm run firefox

# Commit only templates
git add manifest-v2.json background/
git commit -m "Update background scripts"
```

## Troubleshooting

### "Extension not loading in Firefox"
- Ensure you ran `npm run firefox`
- Check `manifest.json` has `"manifest_version": 2`
- Check background script is `background-v2.js`

### "Badge not updating in Firefox"
- Verify `background-v2.js` uses `browserAction` not `action`
- Check Firefox console: `Ctrl+Shift+J`

### "Extension not loading in Chrome"
- Ensure you ran `npm run chrome`
- Check `manifest.json` has `"manifest_version": 3`
- Check background script is `background.js` (service worker)

### "Git conflicts on manifest.json"
- `manifest.json` shouldn't be committed
- If it is, run: `git rm --cached manifest.json`
- Add to `.gitignore` if needed
