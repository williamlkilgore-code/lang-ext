PLACEHOLDER ICONS NEEDED

The extension requires three icon sizes:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

TEMPORARY SOLUTION FOR DEVELOPMENT:
You can use the icon.svg file provided and convert it using online tools like:
- https://cloudconvert.com/svg-to-png
- https://www.aconvert.com/image/svg-to-png

Or create simple colored squares as placeholders using any image editor.
The extension will work without icons, but Chrome will show a default placeholder.

PRODUCTION:
For production release, you should create professional icons that represent
the extension's purpose (learning Persian/Farsi through Arabic roots).
